project Title

The student grade calculator is a shell scripting project that allows users to add student records, calculate grades, check pass/fail status. It uses a menu driven interface in the Linux terminal and stores student information in text files. The project demonstrates shell scripting concepts such as loop, conditional statements, and file handling

## Installation

Feature 1: Input Current Student Grade                                                 

Description: This feature allows the user to enter their current grade in a course as a percentage. The program will ask the user to input their current overall grade so that it can use this information to perform calculations. The current grade is an important part of the student grade calculator because it provides the starting point for determining the student's academic 

Feature 2: Display The Required Student Grade

Description:This feature calculates and displays the grade a student needs to achieve on an upcoming test, assignment, or final exam to reach their desired overall course grade. The program will use the student's current grade, the percentage weight of the remaining assessment, and the target final grade to determine the required mark. After completing the calculation, the program will display the required grade as a percentage so that the student can clearly understand what they need to achieve. For example, if a student wants to finish a course with an overall grade of 80%, the calculator can determine what mark they need on their final exam to reach that goal. This feature helps students set realistic academic targets, understand their progress, and plan how much effort they may need to put into their remaining coursework.



## Usage 

Our students' grade calculator will be designed to be simple and easy to use. Students will enter their grades and the application will perform the calculations automatically. It will display their average grade , highest grade, lowest grade required passing grade and whether they are currently passing or falling.

The application will also help reduce mistakes that students might make when calculating their grades manually instead of spending  time doing their math students will be able to enter their marks and receive their results quickly
